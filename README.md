# satoshisoybr.github.io
Índice open source que decompõe o preço da soja em Chicago, dólar e prêmio comercial. Propõe incorporar Bitcoin como referência monetária ou componente alternativo ao prêmio, com metodologia aberta e auditável. Base para pesquisas sobre hedge, derivativos e liquidez. A plataforma apresenta preços; não executa operações financeiras.
